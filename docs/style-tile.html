色板 纸 · 墨 · 地图 · 状态

永远不用纯白和纯黑：白用「纸」，黑用「墨」。层次靠明度，不靠饱和度。

地图层 全国 / 区域

摊开的纸、顺时针倾斜 1.2°、折痕、等高线、三级线宽的路网、朱红的已走路线（铅笔虚线）、 墨色的计划路线（点线）、盖章。地名都有纸色衬底，压在任何底色上都读得清。

路段层 同一套颜色，三种光

地平线固定在 0.72 高度，天空占七成——这是空旷感的来源。风景用平涂色块，不上渐变； 速度感只靠虚线移动、近景树和 1–2px 的颠簸，不靠模糊和镜头拉伸。

卡片就是一小张纸：1px 墨线、4px 小圆角、一点点投影。按钮是铅笔框，悬停时线变深。 不用发光、不用渐变、不用大圆角。

符号系统 几何 + 点表示等级

全部 2px 描边、几何形状。服务等级不换图标，只画点：加油 1 级 = 一点，3 级 = 三点。 比画三个不同的图标清楚得多，而且能直接参与数值表达。

三个字体三种角色：宋体 用于地图与标题 · 楷体 用于心情与事件正文 · 黑体 / 等宽 用于操作与数字。
