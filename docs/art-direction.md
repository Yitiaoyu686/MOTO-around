# 摩旅模拟 · 视觉方向 v1.0

> 配套：`docs/design.md`（玩法方案）、`docs/style-tile.html`（可视化样张，双击打开看）
> 约束：**纯 Canvas 程序化绘制，不依赖任何外部图片/字体/贴图。**

---

## 1. 风格命名

# 「纸图」Paper Atlas

> 一张被翻旧了的中国公路地图，上面有人用铅笔标了路线、盖了章、折了角。

**一句话：像一本旅行手账，不像一款手游。**

## 2. 三条铁律

1. **一切皆有纸感** —— 画面底层永远有一层极淡的纸纹与颗粒，白色不存在，最亮是纸黄。
2. **颜色少，靠明度分层** —— 任何一屏 ≤ 6 个主色。层次用明暗拉开，不用饱和度堆。
3. **线条只用于信息** —— 风景是色块（平涂），线条只留给地图路网、UI 边框、手写标注。

再加一条隐含规则：**留白是风格的一部分**。天空要空，地图要空，卡片要空。

## 3. 为什么不是别的

| 备选 | 优点 | 为什么不选 |
| --- | --- | --- |
| 黄昏剪影（高对比剪影 + 暖色天空） | 氛围极强，情绪到位 | 地图层几乎无法套用；白天场景难处理；只能做"某一个时刻" |
| 低多边形地形（Low-poly） | 地图好做、现代感强 | 太冷、太"产品"，没有人情味，和"旅行手账"叙事冲突 |
| 像素风 | 成本低、有复古味 | 地图要缩放（全国 ↔ 路段），像素在不同缩放级别会崩 |
| 3D 写实 / 照片贴图 | 视觉冲击 | 和"程序化绘制、无素材"的约束直接冲突 |

选「纸图」的核心原因：**它天生适配"地图 + 缩放 + 标注"这种玩法，而且用 Canvas 就能画好。**

## 5. 字体

不引入外部字体，只用系统栈 + 排版技巧。

| 用途 | 字体栈 | 处理 |
| --- | --- | --- |
| 地图地名 / 标题 | `"Songti SC","STSong","SimSun",serif` | 加粗 + `letter-spacing:.08em`，宋体天然有"印刷地图"感 |
| 事件卡 / 日记正文 | `"Kaiti SC","STKaiti","KaiTi",serif` | 楷体，手写味，用于有大段心情文字的地方 |
| UI 正文 / 按钮 | `system-ui,"PingFang SC","Microsoft YaHei"` | 干净，保证可读 |
| 数字（速度/里程/时间） | `"DIN Alternate","Roboto Mono",ui-monospace` | **必须等宽**（`tabular-nums`），数字跳动时不抖 |

原则：**三种字体三种角色，不要混用**。宋体=地图，楷体=心情，黑体=操作。

## 7. 地图层视觉规范

- **质感**：整张地图是一张摊开的纸，**顺时针倾斜 1.2°**，右下方一层柔和投影，四角有淡淡的折痕线。
- **等高线**：用 3 组极淡的曲线（`#A79B8A` 8% 透明）表现地形，不填色块地形，只填"海拔色带"作为背景。
- **省界**：1px 点划线，`#A79B8A` 40%。
- **路网线宽三级**：国道 3px、省道 2px、县道 1px。**粗细就是信息。**
- **文字必有衬底**：任何地名/数字，底下垫一个 3px 的纸色描边（halo），保证压在任何底色上都读得清。
- **"你在这里"**：一个朱红圆点 + 一圈呼吸的外环 + 一个朝向前方的小三角。
- **路线**：已走 = 红色虚线（像铅笔画的）；计划 = 墨色点线。两种质感区分"发生过"和"打算过"。
- **打卡过的地方**：在地名旁边盖一个小方块印章（墨绿），盖歪一点点更好。

## 8. 路段层视觉规范

- **地平线固定在画面高度 0.72**。天空占 70%，这是"空旷感"的关键。
- **三层山**：远 / 中 / 近，各自用平涂色块 + **1px 略深的上边缘线**（手绘感来源）。不做渐变填充。
- **摩托在画面宽度 30% 的位置**，永远面向右，剪影为主 + 3–4 个色块上色（油箱/头盔/行李）。
- **不做透视**：这是侧视图，不是伪 3D。路就是一条横带。
- **速度感靠三样东西**：路面虚线的移动速度、近景树的移动速度、摩托 1–2px 的上下颠簸。**不靠模糊、不靠镜头拉伸。**
- **天气**：
  - 雨 = 细斜线粒子（不透明度 45%），不加溅射，不加积水反射
  - 雾 = 底部向上渐白的纸雾（用纸色，不用白色）
  - 夜 = 整体压暗 + 车灯一个暖色锥（不透明度 42%），**不要加辉光**

## 9. UI / 组件

- **卡片** = 一小张纸：`#0F1524` 换成 `paper-2`，1px `ink-3` 描边，圆角 4px（小圆角，不要 16px 那种"现代 App"感），右下角一点点投影。
- **按钮** = 铅笔框：1px 墨线，悬停时线变粗 + 填充 8% 墨色。**不用发光、不用投影按钮、不用渐变。**
- **进度条** = 手绘刻度尺：底是一条细线，上面每隔一段一个短刻度，走过的部分变成朱红。
- **事件卡**：标签像盖的章（旋转 -2°，墨绿边框），标题宋体，正文楷体。
- **收集册**：网格状，每个格子是一个盖章位，空的显示虚线框。

## 10. 手绘感怎么做（技术，很关键）

Canvas 画直线的默认效果是"机器味"，只要加两步就有手绘味：

1. **抖动描边**：把每条直线切成 4–6 段，每段端点加 ±0.6px 的随机偏移。
   ```
   jitterLine(a, b, seed) → 用固定 seed，逐帧不变
   ```
   ⚠️ **seed 必须固定**。每帧重新随机的话，线条会疯狂抖动闪烁，非常廉价。

2. **纸纹叠加**：离屏 canvas 生成一次 512×512 噪点，`createPattern` 平铺，`globalAlpha ≈ 0.05`。
   再加一层 45° 的极淡斜线，模拟印刷网点。

3. **印刷网点**（可选）：地图的大色块用半调点阵填充而不是纯色，会瞬间有"老地图"味。用 pattern 实现。

## 11. 动效

- **转场**：地图局部放大进入路段层，像镜头推近纸张，0.6s，`ease-out`。不回退动画。
- **数字**：变化时滚动缓动 0.25s，等宽字体。
- **相机呼吸**：整体 1–2px 的缓慢浮动，周期 6s。让静止画面"活着"。
- **盖章**：落下时缩放 1.3 → 1.0，0.18s，带一点点位移。
- **禁止**：全屏闪白、屏幕震动、光晕扩散、粒子爆裂。

## 12. 音频（可选，WebAudio 合成）

| 声音 | 说明 |
| --- | --- |
| 发动机 | 低频锯齿波，频率随速度，音量很小 |
| 风 | 白噪声 + 带通，速度越高越响 |
| 雨 | 白噪声高频段 |
| 翻纸 | UI 切换时的短促噪声脉冲 |
| 盖章 | 低频"咚" + 短衰减 |

全部默认静音，`M` 开关。

## 13. 明确不要

- ❌ 霓虹 / 赛博 / 高饱和渐变（"手游风"）
- ❌ 纯白、纯黑
- ❌ 大圆角、玻璃拟态、投影按钮
- ❌ emoji 当图标
- ❌ 3D 写实、照片贴图
- ❌ 像素风
- ❌ 卡通吉祥物 / 拟人化动物
- ❌ 光晕、粒子爆裂、屏幕震动

## 14. 验收标准

画风做对了，应该满足这 4 条：

1. **截图能当明信片**：任意一帧截图，不解释也像一张旅行手账的照片。
2. **去掉颜色也能看懂**：路网靠线宽分级，标注靠字号分级，灰度下信息层次依然成立。
3. **纸感有但不脏**：颗粒存在，但不能影响文字可读性（正文对比度 ≥ 4.5:1）。
4. **缩放到全国和缩放到路段，是同一套语言**：同一个朱红、同一套字体、同一种描边，不是两种美术。
